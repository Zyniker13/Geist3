# 0006: App toolchain — Swift 6, Swift Testing, XcodeGen

## Context

ROADMAP.md fixes the app side: Swift 6, SwiftUI, Swift Charts, one multiplatform target for iPad and Mac, a `ZTopKit` Swift package, XcodeGen for the project file. What remains to decide is how the project is generated, built and tested.

## Decision

- `app/project.yml` (committed) is the source of truth; the `.xcodeproj` is generated by XcodeGen at build time and never committed.
- `ZTopKit` lives in `swift/ZTopKit` and is tested with Swift Testing (`Testing`, `#expect`).
- The app target is one multiplatform target (`platform: [iOS, macOS]`), deployment targets iOS 18 / macOS 15, linking ZTopKit as a local package.
- Builds in check.sh and CI use `xcodebuild` with `CODE_SIGNING_ALLOWED=NO` and generic destinations (`generic/platform=iOS Simulator`, `generic/platform=macOS`); no signing is needed for build-only.

## Consequences

- No checked-in project file to drift; regenerating is one command (`xcodegen generate`).
- Swift Testing is what Swift 6 ships with, so ZTopKit tests need no XCTest bridging.
- Generic destinations keep CI free of device lookups; screenshots for later parity items are taken on a booted iPad simulator during the app milestones (M5+).
